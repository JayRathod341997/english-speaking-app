# Master Learning Plan — Bilingual Vocabulary (English + Gujarati)

A single study plan covering **all 4 categories (160 words)** in this library. Work through one category at a time (~10 days each, ~6–8 weeks total), 15–20 minutes a day.

**Files you'll use (everything is now consolidated)**
- `vocabulary_index.json` — all word details + mini-dialogues + each category's embedded `quiz`
- `vocabulary_flashcards_all.csv` — one combined Anki/Quizlet deck (filter by the `Category` column)

| 2 | Places | 40 | Days 11–20 |

## How to study (applies to every category)

You learn a word by **meeting it again at growing gaps** (spaced repetition) and **using it in your own sentences** (active recall). These are intermediate–advanced words, so focus on the `collocations` and `usage_note`, not just the meaning.

Each category has **6 batches** (its subcategories). Learn one batch a day.

### Daily loop (15–20 min)
1. **Read & understand (3 min):** each word's English + Gujarati meaning and `usage_note`.
2. **Say it aloud (3 min):** use `gujarati_pronunciation`, 3 times each.
3. **Learn the chunk (4 min):** memorise the `collocations` (advanced fluency is built on fixed phrases).
4. **Make it yours (4 min):** write **2 of your own sentences** per word.
5. **Dialogue practice (3 min):** read that category's matching mini-dialogue aloud.
6. **Flashcards (3 min):** review today's batch + yesterday's in Anki/Quizlet.

### 10-day schedule per category (spaced repetition)
Each new batch is reviewed again on **Day +1, +3, and +7**.

| Day | Learn new | Review (spaced) | Quiz |
|-----|-----------|-----------------|------|
| 1 | Batch 1 | — | |
| 2 | Batch 2 | Batch 1 | |
| 3 | Batch 3 | Batch 2 | |
| 4 | Batch 4 | Batch 3 + Batch 1 | |
| 5 | Batch 5 | Batch 4 + Batch 2 | ✅ **Quiz #1** (Q1–Q8) |
| 6 | Batch 6 | Batch 5 + Batch 3 | |
| 7 | — | Batch 6 + Batch 4 + Batch 1 | |
| 8 | — | Batches 1–3 (all) | |
| 9 | — | Batches 4–6 (all) | |
| 10 | — | All 40 words | ✅ **Quiz #2** (all 15) |

> After Quiz #2, re-test only the words you missed the next day. A category is "done" when you score **≥ 90% on Quiz #2** and can hold its 5 mini-dialogues out loud **without looking**.

### Speaking practice (do daily)
- Use 5 of the day's words in real conversation (or talking to yourself).
- Record a 30-second voice note with the day's batch and listen back once.
- Describe something real with the day's words (a place, a meal, an outing, your day).

### Quick tips
- The Gujarati pronunciation is a guide — Google "pronounce <word>" once for tricky ones (e.g. *cuisine*, *sauté*, *foyer*, *itinerary*).
- Learn **phrases, not just words**: *by all means*, *in the heart of*, *make the most of*, *season to taste*.
- **5 minutes daily beats 1 hour weekly** — consistency builds memory.
